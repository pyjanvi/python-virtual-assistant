# Virtual AI Assistant

A Python-based virtual assistant with a modern web interface, voice input, and voice responses.

## Features

- 💬 Text-based chat
- 🎤 Voice input using Web Speech API
- 🔊 Voice responses using browser speech synthesis
- ⚡ Quick action buttons
- 🕐 Current time response
- 👋 Greeting and basic conversation
- 🌐 FastAPI backend
- 💻 Responsive web interface

## Technologies Used

- Python
- FastAPI
- JavaScript
- HTML
- CSS
- Web Speech API
- Uvicorn
